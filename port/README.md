# Portfólio Lucas Robson

Portfólio clean, branco e responsivo.

## Arquivos

- `index.html` — estrutura
- `style.css` — visual e responsividade
- `script.js` — menu mobile, animações, filtro dos cursos e formulário

## Como usar

Abra `index.html` no navegador.

Para publicar no GitHub Pages, envie os três arquivos para o repositório e deixe o GitHub Pages apontando para a branch/pasta correta.

## Observação

Os logos das tecnologias são carregados pelo Devicon via CDN. Se quiser trabalhar 100% offline, substitua os ícones por SVGs locais.
